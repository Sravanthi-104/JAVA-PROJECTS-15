# Java Beginner Projects

This repository contains a collection of beginner-friendly Java console applications created while learning the fundamentals of Java programming. These projects helped me practice core programming concepts such as user input, conditional statements, switch expressions, mathematical operations, and string handling.

## Projects

### 1. Calculator
A console-based calculator that performs:
- Addition
- Subtraction
- Multiplication
- Division
- Modulus

**Concepts:** Scanner, Switch Expressions, Arithmetic Operators

---

### 2. Compound Interest Calculator
Calculates the final amount using the compound interest formula.

**Concepts:** Math Library, Variables, User Input

---

### 3. Mad Lib Game
Generates a fun story based on words entered by the user.

**Concepts:** Strings, Scanner, String Concatenation

---

### 4. Shopping Cart
Calculates the total price of purchased items based on price and quantity.

**Concepts:** Variables, Arithmetic Operations, User Input

---

### 5. Weight Converter
Converts weight between kilograms (kg) and pounds (lbs).

**Concepts:** If-Else Statements, Mathematical Calculations

---

## Technologies Used

- Java
